Ubuntu / Debian (.deb package)

curl -fsSL https://raw.githubusercontent.com/ngkhhuy/bamboo-viet/main/scripts/install.sh | bash

# Hoặc cài đặt gói .deb mới nhất:
# sudo dpkg -i bin/ibus-bamboo-viet_1.0.1_amd64.deb
# ibus restart

CÂU HỎI THƯỜNG GẶP

Giải Đáp Thắc Mắc

Những câu hỏi phổ biến nhất khi cài đặt và sử dụng Bamboo Viet trên Linux.

Bamboo Viet đã được tối ưu sẵn: đối với các terminal độc lập (Gnome-terminal, Kitty, Alacritty, Ghostty...), bộ gõ tự động dùng Chế độ 5 (Forward as Commit). Nếu bạn làm việc nhiều với VS Code Integrated Terminal, hãy mở bamboo-viet-gui -> Tab 2 và chọn Chế độ 1 (Pre-edit gạch chân) để không bao giờ bị dính lỗi xóa lùi hay lặp chữ!

Bamboo Viet là phiên bản nâng cấp toàn diện: khắc phục dứt điểm lỗi lặp từ Enter trong Chat (Telegram, Slack, Zalo), tối ưu hóa chuyên sâu Terminal & VS Code, tự động khôi phục từ tiếng Anh (như linux, box), hỗ trợ bỏ dấu muộn (`hopwj` → `hợp`), và đi kèm Bảng điều khiển GUI đa tab chuẩn phong cách UniKey.

Có! Dự án hỗ trợ trọn vẹn cả IBus lẫn Fcitx5 (với module C++ fcitx5-bamboo-viet addon), giúp bạn thoải mái lựa chọn framework phù hợp với desktop environment của mình (GNOME, KDE Plasma, Hyprland, XFCE...).

Bạn mở bamboo-viet-gui -> nhấn nút Bảng gõ tắt, hoặc chỉnh sửa trực tiếp file text tại ~/.config/ibus-bamboo/ibus-bamboo.macro.text theo cú pháp tu_viet_tat:tu_day_du.
