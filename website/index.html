Bảng Điều Khiển Chuẩn Phong Cách UniKey

Không cần gõ lệnh phức tạp! Bamboo Viet đi kèm giao diện đồ họa GUI (GTK3) lấy cảm hứng từ UniKey huyền thoại trên Windows, giúp bạn dễ dàng chỉnh kiểu gõ, bảng mã, phím tắt và macro gõ tắt chỉ trong vài cú click.

  • ✓
    Đa dạng bảng mã & kiểu gõ: Hỗ trợ Unicode, TCVN3 (ABC), VNI Windows, Unicode Tổ Hợp, VIQR cùng các kiểu gõ Telex, VNI, Simple Telex.
  • ✓
    6 Chế độ gõ linh hoạt: Pre-edit (gạch chân), Surrounding Text (xóa lùi thông minh), ForwardKeyEvent, Forward as Commit (Terminal).
  • ✓
    Trình quản lý Macro & App Presets: Tùy chỉnh danh sách gõ tắt phong phú, thêm ứng dụng ngoại lệ chỉ bằng 1 nút bấm.

Cài Đặt Dễ Dàng Chỉ Với 1 Lệnh

Hỗ trợ đầy đủ các bản phân phối Linux phổ biến nhất hiện nay.

Ubuntu / Debian (.deb package)
# 1. Tải gói cài đặt .deb mới nhất từ mục Releases
wget https://github.com/bamboo-viet/bamboo-viet/releases/latest/download/ibus-bamboo-viet_1.0.0_amd64.deb

# 2. Cài đặt vào hệ thống
sudo dpkg -i ibus-bamboo-viet_1.0.0_amd64.deb || sudo apt-get install -f -y

# 3. Khởi động lại bộ gõ IBus
ibus restart
1

Kích hoạt trong Settings

Tùy biến & Trải nghiệm

CÂU HỎI THƯỜNG GẶP

Giải Đáp Thắc Mắc

Những câu hỏi phổ biến nhất khi cài đặt và sử dụng Bamboo Viet trên Linux.

Bamboo Viet là phiên bản cải tiến sâu tập trung vào môi trường Linux hiện đại. Dự án sửa dứt điểm lỗi lặp từ Enter trong các ứng dụng Chat (Telegram, Slack, Messenger), khắc phục độ trễ D-Bus trên LibreOffice/Google Docs, tối ưu Wayland native và đi kèm Bảng điều khiển GUI phong cách UniKey tiện dụng.

Có! Dự án hỗ trợ trọn vẹn cả IBus lẫn Fcitx5 (với module C++ fcitx5-bamboo-viet addon), giúp bạn thoải mái lựa chọn framework phù hợp với desktop environment của mình (GNOME, KDE Plasma, Hyprland, XFCE...).

Bamboo Viet đã được tối ưu hóa sẵn cho Wayland với cơ chế Surrounding Text thông minh (Chế độ 2). Bạn không cần cấu hình biến môi trường phức tạp; chỉ cần cài đặt và chọn bộ gõ trong System Settings là hoạt động ngay.

Bạn mở Bamboo Viet Control Panel -> nhấn nút Mở rộng -> chọn mục Bảng gõ tắt, hoặc chỉnh sửa trực tiếp file text tại ~/.config/ibus-bamboo/ibus-bamboo.macro.text theo cú pháp tu_viet_tat:tu_day_du.
